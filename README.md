# Kathisa
Aplicación web de gestión para la educación
Descripción del proyecto
El proyecto consiste en desarrollar una plataforma web para la gestión académica de instituciones educativas y organizaciones de formación. Permitirá administrar cursos, gestionar las inscripciones de los estudiantes, registrar la asistencia y las calificaciones, y organizar la información académica. La plataforma contará con diferentes roles, como organizadores, instructores y estudiantes, con permisos según sus funciones.
Objetivo general
Desarrollar una plataforma web para gestionar cursos de formación, facilitando la administración de las inscripciones de los estudiantes, el registro de asistencia, el seguimiento de las calificaciones y la organización de la información académica, de acuerdo con los permisos de cada tipo de usuario.
